Explore this draft

Open Games, choose a tile, and select Instructions to see the planned rules. View game layout opens the shared play screen. The Profile button previews the future local profile menu. Disabled play and save buttons show features that are not ready yet.

Use Tab to move between links and buttons. Press Enter to activate them, and Escape to close a menu.

Snake

Use the arrow keys to change direction. Collect food to earn points. Hitting a wall or your own body ends the run.

Planned controls: Arrow keys

View Snake layout →

Pong

Move your paddle with the Up and Down arrow keys. Return the ball and score when the computer misses. The match target will be set during development.

Planned controls: Up and Down arrows

View Pong layout →

Memory Match

Select two cards to reveal them. Matching cards stay face up; different cards turn back over. Match every pair to finish the board.

Planned controls: Click or tap

View Memory Match layout →

Circle Hop

Press Space or tap the game area to jump. Clear the shapes in your path and keep going to increase your score. Touching an obstacle ends the run.

Planned controls: Space or tap

View Circle Hop layout →

Medieval RPS

Each choice beats two others and loses to two. Identical choices tie. Sword beats Archer and Catapult. Archer beats Catapult and Dragon. Shield beats Sword and Archer. Catapult beats Shield and Dragon. Dragon beats Sword and Shield.

Planned controls: Click or tap

What will be saved later

Five original games are planned to use local profiles for supported records and progress. These profiles will stay in the same browser and will not be online accounts. Doom will use the selected runtime's own save features until profile integration has been tested.
