About Simple Code Games

A small collection of browser games for students, casual players, and anyone taking a short break.

What we are making

Simple Code Games brings Original Doom, Snake, Pong, Memory Match, Circle Hop, and Medieval RPS into one consistent website. Choose a tile, learn the controls, and enter a shared game layout.

The goal is quick, understandable access to familiar games while practicing web programming and basic game design.

Meet the team

Ian Catterton and Victoria Mason are Computer Information Sciences students at Shepherd University. This website is a project for CIS 332 Web Programming, Fall 2026.

Where the project stands

Original Doom (shareware Episode 1), Snake, Circle Hop, and Medieval RPS are playable. Local profiles use unique usernames and passwords, keep one save per game, and appear on local leaderboards. Scores and profiles stay in the same browser and site address. Pong and Memory Match are still in development.

Vue 3 is planned for a later stage. This initial draft uses ordinary HTML, external CSS, and a moderate amount of JavaScript for navigation, menus and game implementation.

Game contributions

Victoria Mason implemented the Snake and Circle Hop gameplay. Both games are now connected to the shared profile saves, pause controls, and leaderboards.

Credits and assets

Doom, Snake, Circle Hop and Medieval RPS use images from their actual game rendering. Pong and Memory Match still use vector illustrations as placeholders.

DOOM is a game by id Software. This site runs the open-source doomgeneric engine, modified for one profile save and local scoring, with the original shareware Episode 1 data. The full paid game is not included. Music uses FreePats instrument samples. Engine source is GPL-2.0-or-later; the game data has its own terms. Download the modified engine source.
