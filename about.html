About Simple Code Games

A collection of browser games made for students, casual players, and anyone taking a short break.

Meet the team

Ian Catterton and Victoria Mason are Computer Information Sciences students at Shepherd University. This website is a project for CIS 332 Web Programming, Fall 2026.

Victoria implemented the Snake and Circle Hop gameplay. The games share the site's profile, save and leaderboard features.

What you can play

  • Original Doom: play the original shareware Episode 1 in your browser.
  • Snake: collect apples, wrap around the edges, and watch for bombs every ten apples.
  • Circle Hop: jump over different shapes as the pace increases every 100 points.
  • Memory Match: memorize 2, 4, 6 and eventually 16 cards, then match pairs without a mistake. Clear a full board to shuffle another and continue the same score.
  • Medieval RPS: choose Sword, Archer, Shield, Catapult or Dragon. Each choice beats two others.

Medieval RPS also offers online multiplayer. Browse rooms, join a random public opponent, or host with an optional password. Both players lock their choices before the result is revealed. Room wins are separate from singleplayer streak rankings.

Pong is still in development.

Profiles, saves and leaderboards

Create a profile with a unique username and password, then sign in on another device to use the same account and see shared best scores. Each game has its own leaderboard showing up to 50 players. The Overall leaderboard awards placement points across the supported games.

Each profile has one local save slot per game on each device. Your best scores sync online, while singleplayer checkpoints stay in the browser where you played. Guest games are not saved or ranked.

How the website is built

The site uses HTML, external CSS and JavaScript for its pages, menus and browser games. GitHub Pages hosts the website. Supabase provides online authentication, profiles and shared leaderboards.

The project brings together web programming, game logic, accessible controls and database features in one collection.

Credits and assets

Doom, Snake, Circle Hop and Medieval RPS use images from their actual game rendering. Pong and Memory Match still use vector illustrations as placeholders.

DOOM is a game by id Software. This site runs the open-source doomgeneric engine, modified for one profile save and local scoring, with the original shareware Episode 1 data. The full paid game is not included. Music uses FreePats instrument samples. Engine source is GPL-2.0-or-later; the game data has its own terms. Download the modified engine source.
