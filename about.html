About Simple Code Games

A small collection of browser games for students, casual players, and anyone taking a short break.

What we are making

Simple Code Games brings Original Doom, Snake, Pong, Memory Match, Circle Hop, and Medieval RPS into one consistent website. Choose a tile, learn the controls, and enter a shared game layout.

The goal is quick, understandable access to familiar games while practicing web programming and basic game design.

Meet the team

Ian Catterton and Victoria Mason are Computer Information Sciences students at Shepherd University. This website is a project for CIS 332 Web Programming, Fall 2026.

Where the project stands

The current milestone focuses on structure and appearance. The pages, responsive game collection, menu previews, and shared gameplay layout are ready to explore. Game logic, local profiles, scores, and saves are planned next.

Vue 3 is planned for a later stage. This initial draft uses ordinary HTML, external CSS, and a moderate amount of JavaScript for navigation, menus and game implementation.

Credits and assets

The tile artwork consists of original vector design illustrations. These are placeholders, not screenshots from working games.

DOOM is a game by id Software. A browser runtime and permitted game data have not been included. Any future integration will identify its source, licenses, and save limitations.
